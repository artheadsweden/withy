# Architecture Decision Records

ADRs record decisions that have already been approved.

They explain *why* a decision was made. The normative Specs define *what OMVCS means*.

Workflow:

1. Design Gap or planned design question identified.
2. Human decision is made.
3. Create ADR.
4. Update affected Specs.
5. Update conformance tests or test plans.
6. Implement.

Use `ADR-TEMPLATE.md`.
