# OMVCS Design Gaps

A Design Gap records missing, ambiguous, or contradictory normative behaviour.

Agents must search the complete specification set before creating a gap.

Allowed classifications:

- `NON-BLOCKING`
- `BLOCKS-FEATURE`
- `BLOCKS-MILESTONE`

A Design Gap may contain candidate directions, but no candidate becomes normative until a human decision is recorded in an ADR and the Specs are updated.

Use `DG-TEMPLATE.md`.
